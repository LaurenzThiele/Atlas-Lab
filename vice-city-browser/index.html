About this map

Every footprint from Overture Maps buildings (release 2026-10-21.0) that touches the box from Miami Beach to Brickell, extruded to its height. When a building has no height, I use its floors x 3.5 m, and when it has neither, 4 m. Towers whose height Overture keeps only on building parts show at their outline height.

The layers this map draws

  • land.geojson.zip: the land, clipped to the map's ground box, as GeoJSON. ODbL 1.0, credit as above.
  • water.geojson.zip: the sea, the bay, lakes and canals, clipped to the same box, as GeoJSON. ODbL 1.0, credit as above.

The buildings layer is too big to keep as a file here. It is built from Overture Maps buildings, release 2026-10-21.0. Rebuild this layer with uv run maps/prepare.py (see the README).
